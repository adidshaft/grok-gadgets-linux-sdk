# Contributing

Python 3.11+ and uv. Run AGENTS.md checks, create a short feature branch and reference a stable local issue ID. Capability handlers must validate their arguments and report observed state; protect retry/reconnect semantics with behavior tests.

Shared [conduct](../grok-gadgets/CODE_OF_CONDUCT.md) and [community policies](../grok-gadgets/community/README.md) remain unpublished sibling references. Maintainer/GitHub owner selection pending. Original contributions Apache-2.0. Protocol changes belong upstream in the gateway and require renewed pin/hash evidence.
