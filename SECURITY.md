# Security

Private reporting route pending publication: notify workspace owner directly during local phase, never create a public issue with a token. Configure GitHub private vulnerability reporting before launch. Do not invent a contact email.

Alpha device transport is unencrypted loopback TCP only. Credentials are per-device and provided via environment; no remote connection is supported. The SDK does not log frames, arguments or exception strings by default. Handler code has local process privileges; only use code you trust.
